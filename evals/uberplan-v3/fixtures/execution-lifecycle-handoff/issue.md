# Execution lifecycle repair

Implementation work is taking too long because Tier 2 defaults to a review board
and final acceptance requires a universal report even when the approved plan is
contained. The last candidate plan chose the correct UberGoal-to-UberAccept
boundary but summarized away several details that a separate implementer needed.

Plan the smallest complete repair. The executor must be able to implement it
without guessing which source bodies, terminal outcomes, external-action
protections, or Tier 3 protections survive simplification.

Do not redesign UberRCA. It remains available for repeated same-family failures
or a material unexpected failure that invalidates the plan.
